# 英语科技写作

## 1. 如何写好引言【introduction】

### 论文结构说明

### 引用功能说明

- 引言：从大背景慢慢缩小，最后落到“我的研究要解决什么问题”，并说明前人做了什么、还缺什么、为什么我要做。

正文：说明“我怎么做、得到了什么结果”。

讨论：从自己的结果再往外扩，解释结果意味着什么、解决了多少问题、和前人研究有什么关系，以及意义、不足和未来方向。
### 一个好的学习方法

- 简短描述作者在每个句子中做什么。
请注意，
功能说明：不是要描述或总结句子在说什么（句子的内容）​；而是要弄清楚句子在做什么（句子的功能）​。
时态识别：识别句子功能的一种方法是查看主要动词的时态。这一句的动词与前一句的时态相同吗？如果不是，作者为什么改变了时态？
- 学习示例
### 写引言之前的原则

- 先想好怎么开头。不管是写一句话还是写一段,落笔之前先琢磨一下——这句怎么接上一句?这段怎么接上一段?别想到哪写到哪,那样读起来会很乱。

然后,你得记住一件事:你自己太熟这个话题了,所以你会觉得什么都是常识,不用解释。但读者不是你,尤其可能是别的专业的人来看,他们没有你脑子里那些背景知识。所以别为自己写,是为读者写。

引言也别急着一句一句憋,先把整个引言规划好——打算讲几段、每段讲啥,心里有谱了再动笔。

还有个坑很多人会踩：引言里说的研究问题、研究空白，跟后面讨论、结论对不上。你前面挖了个坑,后面得填上,首尾得呼应。

开头别一下子跳太快,不能上来就是"这个领域很重要",然后下一句直接扎进特别细节的东西里,中间得有个过渡,一层层收窄。

最后一点，是关于"读起来累不累"的。信息太密集，读者眼睛跟不上脑子的处理速度，读着就费劲。这时候就该拆句子、加例子、多分几段，让内容喘口气。

归根结底就一句话：写之前先想清楚，写的时候为读者着想，别让人跟不上你的思路。
### 具体准则

- 句1部分要求
  - 功能说明
    - 许多研究论文首先要论证这一主题如何或为什么有用或重要。因此，在你的目标文章中，你通常会在第一句话中发现一些表达方式，如much study in recent years（近年来的许多研究）​，或者a major role or widely-used（起重要作用或被广泛使用）​。
  - 动词时态
    - 写科研论文时，时态要跟“时间范围”对应：过去发生的具体事情用过去时；从过去持续到现在、或强调近年来研究进展时用现在完成时；描述当前事实、普遍规律和现状时用一般现在时。涉及“近年来、目前、最近几年”等相对时间表达时，应尽量改成明确的年份或时间范围，避免论文过几年后显得过时。
  - 如何开头
    - 引言开头要先让读者开始知道你这是啥领域、方面的研究，再把他一步步带到你的研究问题。不要一上来就钻进自己的小问题里。
  - 第一句最好从“大家都能理解的共同背景”开始。
先找一个大多数读者都知道、都能接受的事实，再慢慢缩小到你的具体研究问题。
也就是：大背景 → 具体领域 → 具体问题 → 我的研究。
背景宁可稍微多一点，也不要少到让人看不懂。
因为你以为“这不是常识吗”，但读者不一定和你是一个方向。特别是跨学科论文，不要一下子从很大的话题跳到特别具体的问题，中间要有过渡。
实在不知道第一句写什么，就去看目标期刊最近的同类论文。
看别人通常从什么事实、概念或者关键词开始，然后照着这种“开场逻辑”写，不是照抄句子。
- 句2部分要求
  - 功能说明
    - 做法跟在第1句和第2句是一样的，只不过方式更具体，通过引用参考文献来支持背景事实和重要性声明。
- 句3部分要求
  - 功能说明
    - 用一个有依据的事实，把句1、句2的大背景进一步具体化，但还不要进入“谁做了什么”的研究综述。
- 句4部分要求
  - 功能说明
    - 从前面的背景介绍，开始转向“这个领域现在有什么问题”。 句4还是“大的问题”，后面再慢慢缩小到你的具体 gap。
- 句5部分要求
  - 功能说明
    - 引出：为什么这个问题很重要，或者在某个具体应用场景下为什么更麻烦。把句4的大问题，放到具体场景里进一步说明，让问题变得更明确。
常见写法：具体应用需求 → 现有方法不满足 → 问题进一步突出
- 句6部分要求
  - 功能说明
    - 开始连接“别人已经做过什么”。
具体规则：把前面提出的问题，和已有研究联系起来，开始告诉读者：别人已经怎么解决这个问题了。
既然前面有这个问题，那别人已经想过什么办法解决？
这里开始引出：
已有方法
已有研究方向
别人尝试过的解决方案
相关文献
- 句7部分要求
  - 功能说明
    - 开始提到该领域的关键研究。
  - 引言中我应该提到多少项研究？
    - 没有固定数量，不是越多越好，只写那些和你的研究真正有关系、而且后面用得上的研究。
1. 不要把你看过的论文全塞进去。
2. 每提一项研究，都要有作用。它至少应该帮助你说明：这个问题以前怎么研究；
现在做到什么程度；
还存在什么问题；
为什么轮到你继续研究。
3. 和自己研究关系不大的，直接删。
判断方法很简单：删掉这篇文献，会不会影响我把研究问题和研究动机讲清楚？
不影响 → 大概率没必要放。
4. 不要为了引用数量把引言写成长篇文献综述。
引言最终是要把读者带到：“所以，本文为什么要做这个研究。”
  - 我如何组织和连接这些研究？
    - 核心要点：不要写成“谁做了什么”的清单，要写清楚“这个领域是怎么一步步发展到你的研究问题的”。
最常用三种方式：
从大到小：领域背景 → 具体问题 → 研究空白。
按类别：同类方法放一起，不同方法分开讲。
按时间：早期怎么做 → 后来怎么改 → 现在做到哪。
- 句8部分要求
  - 功能说明
    - 这里开始：指明研究的问题或空白。
从这里开始你转向自己研究的论文或工作，以及将要解决的具体问题。通常，这可以通过确定现有知识的空白或通过指出已有研究中存在的问题来进行。
- 句9部分要求
  - 功能说明
    - 指明当前你写的论文或研究工作。如：​“The present paper presents a set of criteria for selecting such a component.”
  - 动词时态选择
    - 描述“本文做什么、研究什么” → 一般现在时。

比如：
This paper presents...
This study focuses on...
This work investigates...

描述“当初为什么做、研究目的是什么” → 一般过去时。

比如：
The aim of this study was...
Our objective was...

如果强调“本文现在的研究目标” → 也可以用一般现在时。

比如：
The aim of this work is...

核心就是：
本文内容用现在时，研究当初的目的用过去时；如果把目标当作论文当前内容来讲，也可以用现在时。
- 句10部分要求
  - 功能说明
    - 主要作用：简单告诉读者“这篇论文具体怎么做”。
只要概括方法就行，不要展开实验细节。
比如可以写：
本文采用了什么材料。
本文使用了什么方法。
本文进行了什么实验或分析。

核心规则：简要交代研究方法，但不要把“方法章节”搬到引言里。
- 句11部分要求
  - 功能说明
    - 句11的作用就是：直接告诉读者“最后做出了什么结果”。用一句话亮出最重要的结果和创新点。
这里不要再讲方法，而是突出最核心的研究成果。
简单规则：
研究结果是什么，就直接说出来。
如果确实有创新，可以用 novel、new、improved 这类词。
如果结果有明显提升，可以用 significantly increased、improved、enhanced 这类表达。
但不要夸大，必须和实际结果一致。
### 全局准则

- 背景信息给多少
  - 开头写多大，取决于你的读者有多“懂行”。
如果是很专业的小领域期刊，读者本来就懂背景，可以直接一点；
如果是跨学科、综合性期刊，就要从更宽的背景讲起。
- 引言里的“背景事实”到底要不要引用文献
  - 如果这个事实是某篇研究“发现出来的”，尤其是比较新、比较具体、可能有争议的结论，要引用文献。
如果这个事实已经变成领域里的公认常识，大家都默认它成立，通常可以不引。
越新、越具体、越有争议的事实，越应该引用；越基础、越公认、越像常识的事实，越可以不引。
还有一个非常实用的判断方法：
如果你担心读者会问一句“你凭什么这么说？”——那最好加引用。
 一个领域的写作习惯、常用时态、哪些事实算“常识”，都会变化，所以最好去看目标期刊最近几年的论文怎么写。
- 时态说明
  - ① 现在还成立吗？
→ 一般现在时
This problem remains challenging.
② 是从过去一直发展到现在吗？
→ 现在完成时
Many studies have investigated this problem.
③ 是某篇具体论文当年做的事情吗？
→ 一般过去时
Zhang et al. proposed a CNN model.
所以引言里最常见的结构其实就是：
现在时：领域现在是什么样
↓
现在完成时：到目前为止大家研究了什么
↓
过去时：具体某些论文做了什么
↓
现在时：但目前仍然存在什么问题
- 什么时候需要把文献引用放在句子的中间？
  - 谁支持哪部分，就把引用放在哪部分后面。【把引用内容弄得再具体一点！】

比如：

Method A improves accuracy (Smith, 2023), but it requires much more computation (Li, 2024).

而不要写成：

Method A improves accuracy, but it requires much more computation (Smith, 2023; Li, 2024).
- 被动、主动语态选择
  - 主动语态：想强调“谁做了什么”时用。
例如：We investigated...
适合突出作者行为，表达更直接。

被动语态：想强调“做了什么”，不关心谁做时用。
例如：Samples were collected...
适合方法、实验流程。

非人称主语：科技论文里很好用。【默认就是用这个】
例如：This study presents...
This paper describes...
Section 2 reviews...
既避免一直写 we，也比被动语态更清楚。

最简单的规则：

强调“人” → 主动语态
强调“过程/对象” → 被动语态
强调“论文/研究本身” → This study / This paper + 主动动词

另外，we/our 要慎用，前后指代要一致，不要一会儿指作者，一会儿又指整个领域的人。
- 分段规则
  - 一段一个中心，中心变了就换段。
首句立意，中间只为它服务，尾句收束或过渡。
150–170词为常态；低于80或高于230，先检查是不是该拆或该收。
检验方法：写完之后，大声读一遍，问自己"这段只讲了一件事吗？" 讲了两件——拆开;讲了半件——说完再往下走。
- 字、段字数长度限制
  - ​​句子长度​​
1. ​​理想句子长度​​
• ​​少于20个单词​​：90%的读者能首次理解。
• ​​20-26个单词​​：期刊论文中常见范围（如引言、方法等部分）。
• ​​超过40个单词​​：仅10%的读者能首次理解，需避免。
2. ​​写作建议​​
• 优先使用​​短句​​（<20词），确保清晰性。
• 避免复杂长句，减少语法错误风险。
• 摘要中平均句长为​​22个单词​​（18个摘要样本统计）。
​​段落与摘要字数​​
1. ​​摘要长度​​
• ​​80-250字​​：多数期刊要求范围。
• ​​核心原则​​：突出核心贡献，避免填充至字数上限。
2. ​​段落长度​​
• ​​典型段落​​：150-170个单词。
• ​​长段落​​：230个单词（需谨慎使用）。
• ​​短段落​​：80个单词（适用于重点强调）。
- 如何让句子连贯起来
  - 第一种方法是重叠，即在下一个句子的开头重复上一个句子的内容。
  - 第二种方法是使用替代形式(This method、These systems)将句子连接在一起。
    - 需要注意的是，当你使用替代形式时，如果你重复使用与第一次使用的完全相同的名词，对读者来说更容易。如果你将某事物描述为一种设备(a device)，下次引用时应该是该设备(this device)，而不是该技术(this technique)或该方法(this method)。你可以在句子的开头用It、They、These或者This来引用，但是对于读者来说可能很难弄清这些单词所指的具体含义。
  - 第三种方法是根本不结束句子，而是用分号把上下文的句子连接起来。当两个句子关系非常紧密并且其中一个非常短的时候，用分号连接句子能起到很好的效果。
  - 第四种方法是使用一个信号（如therefore或however）来传达句子的功能。
    - 信号词（连接词）核心总结

核心原则：
用于连接句子或段落，表达明确逻辑关系（尤指因果关系）。需注意避免歧义（如时间与因果），不明确的因果需补充说明。

六大分类及核心词汇：

1. 表示原因：
due to, because, since, as
注意：as/since 易产生“时间”歧义，需确保语境清晰。

2. 表示结果：
therefore, hence, thus, so, consequently
强调直接因果关系。

3. 表示对比/差异：
however, whereas, while, but, by contrast
注意：on the contrary 仅用于完全对立，并非普通对比。

4. 表示意外/转折：
although, despite, nevertheless, yet, even so
注意：however/but 也可表示对比。

5. 表示并列/清单：
in addition, moreover, furthermore
注意：besides 语气更强，适用于有说服力的语境。

6. 表示过程/话题转换：
regarding, as for, with respect to
常用于句式开头。

自我编辑提示：
写完句子后，检查信号词是否准确连接了前后逻辑。用好信号词，能帮你察觉逻辑跳跃，是极佳的自我编辑工具。

## 2.  怎么写方法【method】

### 编写方法部分之前

- 看笔记
### 具体准则

- 句1部分要求
  - 功能说明
    - 方法第一句要先给读者一个“总览”，不要直接进入细节。
一般交代：
研究什么 → 对什么做 → 数据/样品从哪来 → 为了什么
比如：
“收集并分析6口井的地下水样品，用于测定溶解 CO₂。”
核心规则：
方法开头先告诉读者“为什么这样做、总体怎么做”，具体参数和步骤后面再展开。
  - 推荐引入方式
    - 引入方法的一种方式是从关于所做和/或所使用的内容的一般陈述开始，然后将其分解以产生细节。对读者来说，这种方式比以高度具体的细节作为开始更有利。
  - 常用的引入方法部分的方式
    - 下面是三种常用的引入方法部分的方式：
1. 先给“方法总览”：一开始先告诉读者你大概怎么做：用了多少样品、什么材料、什么设备、做了哪些测试、目的是什么。适合让读者先建立整体概念。
2. 先介绍“材料/设备”：如果材料或设备本身很重要，就先说：它从哪里来、为什么选它、有什么关键特性。适合材料、化学、工程类研究。
3. 从“研究目标”接进方法直接承接引言最后的问题：“为了验证……”“为了评估……”“为了解决……”，然后说明采用了什么方法。这种衔接最自然也是最推荐的写法。
- 句2部分要求
  - 功能说明
    - 补充“为什么选择这个研究对象/地点/材料”。
主要写三类信息：
1. 研究对象在哪里、是什么。
2.它有什么关键特点，为什么适合本研究。
3.有没有前人研究证明这种选择是合理的。

句2马上解释“为什么偏偏选这个地方、这些样品或这些材料”。背景信息不要讲太多，只写读者理解后面方法所必须知道的内容。
  - 提供多少背景信息
    - 只补“读者理解你的方法所必须知道的背景”，不要什么都讲。
主要判断两件事：
1. 读者是否已经知道这个对象/地点/材料/设备是什么？
2. 读者是否知道你为什么要这样选择？
如果不知道，就要补充。方法部分不仅要写“我怎么做”，还要说明“为什么这样做”。比如：
1. 为什么选这个研究地点。
2. 为什么选这种材料。
3. 为什么用这个设备或软件。
4. 为什么采用这个处理步骤。
5. 必要时用事实或前人研究来证明你的选择是合理的。
核心：背景信息 = 让读者既知道“你选了什么”，也知道“你为什么这样选”。
- 句3部分要求
  - 功能说明
    - 句3的作用：开始正式进入具体步骤，但先给这一段一个“小总览”。
比如这里先说：
一共收集了18个样本，每口井取3个。
它不是马上讲每一步怎么操作，而是先告诉读者：这一步整体做了多少、怎么分配、总体规模是什么。然后后面再展开具体步骤。
规则可以记成：
先总述这一段要做什么 → 再往下写具体细节。
如果前面的方法开头已经讲得很清楚，这种总述句不一定必须重复；要不要写，看目标期刊常见写法。
- 句4、句5部分要求
  - 功能说明
    - 句4、句5的作用：开始把方法步骤写具体。
主要写清楚三件事：
先做什么 → 再做什么 → 到什么条件后进行下一步。

例如这里：
先抽掉井里的滞水
→ 抽水过程中监测 pH
→ 等 pH 稳定后再取样。
同时要交代关键设备和条件，比如用了什么仪器、什么时候停止、什么时候进入下一步。

重点不是“越详细越好”，而是：
别人按照你的描述，基本能重复这个过程。

顺序词也不要只写 then、next，最好写清条件关系，比如：
prior to：在……之前
during：在……过程中
until：直到……
at which point：到这个时候再……
- 句6部分要求
  - 功能说明
    - 继续补充关键操作，并说明“为什么这样做”。
主要写清楚三件事：
做了什么 → 在什么条件下做 → 为什么这样做。

例如这里：
样品装入棕色玻璃瓶
→ 密封后在 5℃ 冷藏
→ 为了防止污染，直到后续分析。

还可以用 tightly、carefully 这类词，适当体现操作的规范和谨慎。
- 句7部分要求
  - 功能说明
    - 句7的作用：说明“后续怎么测”，并交代你用了什么已有方法。
主要写清楚：样品送到哪里 → 测了什么 → 用了什么方法 → 方法来自哪里。
如果方法是别人已经建立的，就要引用文献。
但不能只写“按照某文献的方法”，还要简单说明关键步骤、设备或参数，因为读者不一定会去翻原文。
如果你对已有方法做了修改，要明确写出来，比如：
using a revised version of the method...
核心规则：
句7 = 交代测定方法 + 引用方法来源 + 简述关键操作。
- 句8部分要求
  - 功能说明
    - 句8的作用：补充“为什么这个方法/参数是合理的”。
主要写：
用了什么设备或参数 → 这个设置有什么优势 → 为什么适合本研究。
比如这里：
检测限为 0.050 mg/L
→ 检测更灵敏
→ 说明这个方法能可靠检测目标物。
核心规则：
不要只写“我用了什么”，还要适当解释“为什么这样选”。
尤其是关键参数、特殊设备或容易被质疑的选择，最好给出理由。
- 句9部分要求
  - 功能说明
    - 句9的作用：主动交代方法中可能存在的问题或局限。
主要写清楚：
出了什么问题 → 可能造成什么影响 → 实际影响有多大 → 为什么结果仍然可信。
不要故意隐藏缺陷。方法部分第一次出现问题时就应该说明，后面讨论或结论中再总结和提出改进。
语气要客观，不要把问题写得像“实验失败”，可以说明问题受到控制或影响较小。
比如：
存在污染风险 → 但接触时间很短 → 样品差异很小 → 因此总体影响有限。
  - 怎么提及问题和局限性
    - 核心就是：承认问题，缩小问题,接上方案——别让问题句是这段话的结尾。用能"减少问题分量"的措辞：承认问题存在，但把它说小、说轻、把责任降到最低，同时突出好的一面或给出解决方案。比如"轻微接触"（brief contact）、"可忽略"（negligible）这类词，就是把问题淡化的常用手法——你不是掩盖问题，是控制它的"存在感"。
### 全局准则

- 补充材料怎么写
  - 虽然将补充材料放在正文之外可以提高可读性，但是大量使用补充材料可能会产生一系列负面影响。
无论格式如何，补充材料都应直接与文本建立超级链接。这样的引文应该是补充材料的具体部分……。
- 参考文献引用问题
  - 已有方法的引用规则：

已有/标准方法：
如果方法来自别人，就要引用；如果已经是领域公认标准，可以少写细节，但最好仍给出处。

不要只写“按某文献的方法”：
读者不一定会去查原文，所以还要简要写清关键步骤、设备或参数。

如果你改过已有方法：
要明确说明“基于某方法修改”，并指出改了什么。

引用位置要准确：
引用要紧跟对应的方法，别全部堆到句末，避免让人误以为整句话都是别人做的。
- 单位制【要求】
  - 检查当前版本中的目标期刊或国际单位制(SI)的缩写和符号的使用。例如：很多期刊建议使用mL而不是ml，以避免1、l和L之间的混淆。

## 3. 怎么写结果【Result】

### 开始写结果内容之前的原则

### 具体准则

- 句1句2部分要求
  - 功能说明
    - 重复和回顾该文章之前提及的研究方法和发现。
- 句3句4部分要求
  - 功能说明
    - 简要总结了本研究中使用的方法。
- 句5部分要求
  - 功能说明
    - 句5的作用：先把读者引到图/表上，再开始解释结果。
内容要求：
先说明“哪张图/表展示了什么”。
不要只写“见图1”，要告诉读者图里主要是什么数据。
图表出现后，正文要接着解释重点趋势，不要让读者自己猜。
图表顺序要和正文叙述顺序一致，先讲哪个结果，就先放对应图表。
不要一上来就直接宣布最重要结论，最好先让读者看到图表，再带着读者一起解释。
- 句6句7部分要求
  - 功能说明
    - 句6：先说明结果与已有研究是否一致。
例如：
in line with previous studies
broadly similar
consistent with

句7：再指出重要的不同或变化。
例如：
However, ...
significantly different
higher/lower than

核心要求：

结果不能只写“图里有什么”，还要告诉读者“这些结果说明什么、和别人相比怎么样”。

遇到明显转折时，最好把 However 这类信号词放在句首，让读者提前知道“下面要讲不同了”。
- 句8部分要求
  - 功能说明
    - 句8的作用：把读者注意力拉到“最值得关注的结果”上。
主要写：
具体结果是什么 → 变化有多明显 → 对应哪张图/数据。
可以适当用评价性词语突出结果，比如：
striking：明显、引人注目的
substantial：显著的、大幅的
marked：明显的
notable：值得注意的
但前提是数据真的支持，不能为了“好看”而夸大。
- 句9部分要求
  - 功能说明
    - 句9的作用：挑出“最重要的结果”重点讲，不要所有结果都写得一样详细。
主要规则：
关键结果 → 给具体数字/变化 → 用评价词突出它为什么重要。
比如：
下降 33% → 而且在高峰期仍保持低水平。
也就是你的主要的比别人优化的点！
不要把所有数据逐个复述，要主动告诉读者“哪个结果最值得关注”。
结果部分可以做简单解释，比如：
These results suggest that...
但只解释“数据直接说明了什么”，更深入的原因、意义和影响留到 Discussion。
- 句10部分要求
  - 功能说明
    - 解释结果“可能说明什么”。
不要把结果说死，可以用 suggest、may、might 这类词。

结构：
结果 → 可能意味着什么。

例如：
“These results suggest that...”
= “这些结果可能说明……”
- 句11部分要求
  - 功能说明
    - 主动说明结果的“可能局限”。

写出哪些没控制、没测量或可能影响结果的因素，同时不要把影响夸大。

结构：
可能影响因素 → 本研究没有完全考虑 → 影响可能有限。

一句话记：
- 这两部分都是结果部分的引入。好的引入方法有四种。核心还是：整体趋势 → 研究目标 → 关键方法 → 总图/总表
  - 先说整体趋势
    - 先告诉读者“结果总体上是什么样”，再展开具体数据。
例如：Overall, X increased with Y.
适合结果很多、需要先看全局的情况。
  - 先重申研究目标/问题
    - 提醒读者“我们到底要验证什么”，然后马上给结果。
例如：To determine whether X affects Y, ...
适合多个研究目标或假设。
  - 先回顾关键方法
    - 简单提醒用了什么关键实验、数据或条件，再进入结果。
适合方法部分很长，或者方法放在补充材料里的论文。
  - 先引出总图/总表
    - 先让读者看最能概括结果的 Figure/Table，再逐项解释。
例如：Figure 1 shows ...
适合数据多、图表是核心的研究。
### 全局准则

- 哪些结果需要详细描述？
  - 需要详细叙述的结果主要有：
核心假设结果：直接验证或推翻研究主要假设的数据（即“关键性”结果）。
主旨支撑数据：对得出论文最终结论起决定性作用的核心发现。
显著或异常发现：具有高统计学差异，或出乎意料但极具研究价值的新颖结果。
但是：结果部分必须简单解释“数据说明什么”，但不要深入讨论“为什么会这样、有什么意义”，这些留到 Discussion。
- 如何诠释结果并且发表评论
  - 如何诠释结果并发表评论：

结果部分可以“解释”，但只解释到数据直接说明什么为止。

可以写：
结果为什么出现（如果能直接从方法、材料、实验条件解释）。
结果说明了什么趋势或关系。
哪些结果特别重要、异常或值得注意。
用少量评价词强调结果，如 significantly、notably、suggest。
- 结果有问题，要不要写？
  - 要写，而且最好第一次出现时就写，不要拖到 Discussion/Conclusion 才承认。

思考顺序：
发现问题
→ 这个问题严重吗？
→ 可能是什么原因？
→ 会不会影响主要结论？
→ 后续怎么改进？

写的时候不要把自己写成“实验失败”，而是：
承认问题 + 说明影响有限 + 给可能原因/改进方向。

例如：
“存在一定影响，但影响较小。”
“这一差异可能与……有关。”
“未来研究可进一步控制……”
- 结果有什么意义，要不要写？
  - 这一部分一定要简单、简短写。

也就是数据报完以后，可以补一句：
“这个结果可能说明什么？”
“它有什么实际价值？”
“和我的研究目标有什么关系？”

常用思路：
结果
→ suggest / indicate
→ 可能含义
→ 可能应用

但不要在 Results 里深入分析机制，详细的“为什么、理论意义、与大量文献比较”留给 Discussion。
- 动词时态问题
  - 写“图表现在显示什么” → 一般现在时
  - 写“你当时做了什么、怎么得到这些数据” → 一般过去时
  - 解释结果时，要看你说的是“当时原因”还是“普遍事实”
  - 表达“这个结果现在仍然成立、具有普遍意义” → 一般现在时
- 结果中的小标题划分问题？
  - 先看目标期刊的论文，观察：
结果部分通常分几个小节；
每个小节大概多长；
小节标题怎么写；
标题是短语还是完整句子。

然后再规划自己的结果部分：

一个小节只负责一个核心结果或一个研究问题。

小节标题要能概括这一节“主要讲什么”，最好让读者只看标题就知道这节内容。

小节之间要有清楚的逻辑，比如：

总体结果
→ 不同方法比较
→ 消融实验
→ 泛化结果
→ 额外分析

最重要的原则：

不是“实验做了几步就分几节”，而是“结果有几个逻辑主题就分几节”。

- 简单结果模板
## 4. 怎么写讨论【Discussion】

### 在写讨论之前

- 这部分核心讲的是：讨论部分要围绕“我的研究到底贡献了什么”来组织，而不是把结果再重复一遍。
写讨论前，先判断你的主要贡献属于哪一类：
方法贡献：结果差不多，但你用了更好的新方法。
结果贡献：你的结果比已有研究更好、更准。
理论/研究方向贡献：你的研究改变了原来的认识，开辟了新方向。
应用贡献：你的研究能解决实际问题，扩大了实际应用。

然后整篇 Discussion 都围绕这个“主贡献”往前推进：
核心结果 → 和前人比较 → 为什么会这样 → 有什么意义 → 主要贡献 → 局限 → 未来工作。
最重要的一条：
不要什么都当贡献写。先确定一个最主要的贡献，再让讨论里的证据、比较和解释都围绕它服务。
### 确定主要价值和贡献

- ●该研究是否获得了与其他研究完全相同或相似的结果，但使用了比现有方法更好的改良的或全新的方法？在这种情况下，主要贡献可能是方法。
●该研究是否获得了比其他研究更好(例如，更准确)的结果？在这种情况下，主要贡献可能是结果本身。
●这项研究是否改变了游戏规则，即它是否开创了新的研究方向/推翻已有工作？在这种情况下，该研究的主要贡献可能是它对文献/研究界的影响。
●该研究是否确定或创建或扩展了应用？在这种情况下，该研究的主要贡献可能是它对工业界或实际应用的影响。
### 序言与讨论对应

### 具体准则

- 句1部分要求
  - 功能说明
    - 讨论部分句1，核心作用就是：一上来先告诉读者“这项研究最重要的价值是什么”。

可以这样写：
研究做出了什么重要成果
→ 相比已有研究新在哪里
→ 对领域有什么贡献或应用价值

如果要说“首次、最大、最全面”等，最好加：

to our knowledge

意思是“据我们所知”，避免把话说得太绝对。

例如逻辑：

“据我们所知，这是目前规模最大的……研究，因此为……提供了重要证据。”

为什么这样开头？

因为 Discussion 不要一上来就钻进细节，而是先让读者重新抓住：

“这篇论文到底做成了什么？为什么值得讨论？”
  - 2种开头方式
    - 第一种：直接亮出你的贡献。
      - 一开始就告诉读者：
这项研究做成了什么？
有什么新贡献？
有什么潜在应用？

适合你的研究贡献比较明确的时候。
    - 第二种：先“重新启动”读者。
      - 因为很多读者可能直接跳到 Discussion，所以可以先简单回顾前面的关键信息，再开始讨论。

可以回顾三种东西：

相关背景
研究空白 / 研究目的
关键结果 / 方法特点

但不要把引言、方法、结果重新抄一遍，只回顾和“主要贡献”有关的内容。

具体回顾什么，要看你的贡献是什么：

如果主要贡献是“新方法”
→ 先回顾旧方法有什么问题，再说你的方法怎么解决。

如果主要贡献是“结果更好”
→ 先回顾关键结果，再讨论为什么更好、意味着什么。

如果主要贡献是“填补研究空白”
→ 先回顾那个空白，再说你的研究怎么回应它。
- 句2部分要求
  - 功能说明
    - 句2的作用：把你的研究放回已有文献中，说明“你到底新在哪、和别人什么关系”。

可以按这个顺序写：
先说新意：
你的研究首次发现了什么、扩展了什么、提供了什么新证据。
再说核心结果：
用一句话概括最关键的发现。
然后和已有研究比较：
是支持了前人的结论？
还是比前人方法更好？
还是发现了和前人不一样的结果？
最后说明影响：
你的结果让这个领域多知道了什么，或者改变了原来什么认识。
  - 我的研究如何纳入已有文献？
    - 把自己的研究放进已有文献里，核心就是回答：

前人做到了什么 → 我的结果和他们相比怎样 → 我的研究多推进了什么。

常见三种情况：

我的方法更好/更快 → 说明改进价值。

我的结果和前人一致 → 说明验证、加强了已有结论。

我的结果和前人不一致 → 说明发现了新问题，可能开出新的研究方向。把自己的研究放进已有文献里，核心就是回答：

前人做到了什么 → 我的结果和他们相比怎样 → 我的研究多推进了什么。

常见三种情况：

我的方法更好/更快 → 说明改进价值。

我的结果和前人一致 → 说明验证、加强了已有结论。

我的结果和前人不一致 → 说明发现了新问题，可能开出新的研究方向。
  - 讨论中应该有多少引文？
    - 讨论部分的引用，核心不是“多”，而是“有用”。
引用主要有三个作用：
1. 说明前人做了什么。
2. 把你的结果和前人比较。
3.  突出你的研究到底新在哪里、贡献在哪里。
写的时候注意：
1. 每个引用都要有明确作用，不能为了凑数量乱加。
2. 可以参考目标期刊最近论文，看 Discussion 一般引用多少、放在哪、同一篇文献会不会重复引用。
- 句3、句4部分要求
  - 功能说明
    - 句3、句4的功能：回顾关键结果，并开始解释它们。

句3：先把最重要的结果重新点出来。
不是把 Results 全部重复一遍，只挑和后面讨论直接相关的关键发现。

句4：对这个关键结果做进一步评价和解释。
说明它为什么重要、和研究问题有什么关系、可能意味着什么。
  - 讨论部分与结果部分重复提及？
    - 原则就是：

结果部分负责“告诉读者发现了什么”。

讨论部分可以再次提关键结果，但不要原样重复，要继续往下解释：

关键结果
→ 为什么会这样
→ 和前人研究有什么关系
→ 回答了哪个研究问题/假设
→ 有什么意义或应用价值

所以：

可以重复“关键结果”，但必须带着新的解释。

不要重复所有数据、数字和图表细节。
- 句5部分要求
  - 功能说明
    - 句5的作用：把“研究发现”进一步落到“有什么用”。

主要写：

结果说明了什么
→ 对实际应用有什么影响
→ 可以给出什么建议

比如这里：

发现成年人风险更高
→ 对公共卫生管理有意义
→ 资源有限时，可以优先筛查成年人。

注意：

有明确应用就直接写。
应用只是可能性时，用 may、could、suggest 等弱化语气。
如果暂时没有实际应用，也不用硬凑，可以写理论价值、知识贡献或未来研究价值。
- 句6、7、8部分要求
  - 功能说明
    - 句6：提出“新问题/新线索”
写你从结果里发现了什么值得继续研究的现象。
句7：说明“这次没解决”
明确说本研究没有测、没有验证，或者数据还不足。
句8：给出“下一步怎么做”
具体说未来应该测什么、比较什么、验证什么。

最简单记：
句6 = 发现问题
句7 = 承认没解决
句8 = 给出解决办法

整体逻辑：
发现一个新问题 → 说明本研究的边界 → 顺势引出未来研究。
  - 局限什么时候放 Discussion？
    - 局限性什么时候提，主要看它是“什么时候发现的”。

研究过程中已经发现的问题
→ 在方法或结果部分首次说明。

分析完结果后才意识到的问题
→ 可以在 Discussion 第一次提出。

如果这个局限还能自然引出后续研究
→ Discussion 里尤其适合写。
  - 如何写作：确定未来工作方向？
    - 未来工作不要只写“以后还需要进一步研究”，要明确告诉读者“下一步具体研究什么”。

可以按这个思路写：
先指出当前还没解决的问题
→ 再说明为什么值得继续研究
→ 最后给出具体下一步：测什么、比较什么、验证什么、扩大什么数据。

这样做有三个好处：
给后续研究一个明确方向，而不是模糊建议。
让你的研究自然延续下去，说明这项工作不是“做到这里就结束”。
把当前局限转化成新的研究问题，增强论文价值。

例如不要只写：

“Future studies are needed.”

而要写成：

“Future studies should evaluate X across larger datasets to determine whether Y remains valid.”
- 句9部分要求
  - 功能说明
    - 句9的作用：用“已有知识/文献”来支撑你的研究结论。

具体逻辑：
先引用一个领域已知事实
→ 再接上你的研究结果
→ 最后说明这个结果支持什么结论或建议。

比如这里：
已有研究：V2D RNA 会长期存在
→ 本研究结果：患者仍可能有后续问题
→ 所以：建议至少随访 10 个月。

核心规则：
讨论后半段也可以继续加背景文献，但必须是为了“支撑你的解释或结论”，不能只是补背景。
- 句10部分要求
  - 功能说明
    - 句10的作用：把讨论收回到“实际应用价值”。

具体逻辑：
研究结果
→ 能支持什么实际决策
→ 能给谁提供什么建议

比如这里：
研究发现
→ 支持按年龄进行随访和治疗
→ 为公共卫生建议提供证据。

核心规则：
不要只说“有应用价值”，要具体写清楚：
“谁可以用、用来做什么、能改善什么”。
### 全局准则

- 区分成就和贡献
  - 成就 = 你这项研究“做成了什么”。

也就是直接回答：
你发现了什么？
你解决了什么问题？
你实现了什么目标？

例如：
我们识别出了一种新的污染物。
我们将预测准确率提高到了 95%。
我们发现 A 与 B 显著相关。
  - 贡献 = 你这个成果“对别人有什么价值”。

也就是回答：
它给领域增加了什么新知识？
它改进了什么方法？
它解决了什么实际问题？
它会怎样影响后续研究或应用？

例如：
为污染物监测提供了新的识别方法。
提高了该模型在实际场景中的可用性。
补充了 A 与 B 关系方面的研究空白。
### 讨论模板

- 具体讨论模板
- 简单讨论模板
## 5. 怎么写结论

### 字体以及段落数量要求

- 结论部分单词的总量为100～200个，通常由一个或两个简短的段落组成，有时甚至包含要点列表。
### 通用结论模板

- 一些参考
  - 1.论文里包含什么 参看第一和第二单元
2.论文/研究取得了什么成就 参看第四单元
3.相关背景信息 参看所有单元
4.研究的空白/目标/需求 参看第一单元
5.方法/途径 参看第二和第三单元
6.带有评价性评论的关键结果 参看第二和第三单元
7.结果的含义 参看第三单元
8.潜在或实际的局限性 参看第二和第三单元
9.潜在或实际的应用 参看第四单元
10.该研究如何提高知识 参看第四单元
11.未来可能的研究方向 参看第四单元
### 如何指出自己的贡献

- 找出自己的贡献
  - 核心是：不要让读者自己猜哪些结论是你做出来的。

先问自己三个问题：
我这项研究新做了什么？
→ 新方法、新数据、新实验、新模型。
我这项研究新发现了什么？
→ 新规律、新关系、新结果、新证据。
这些东西比以前多带来了什么？
→ 提高性能、验证旧结论、填补空白、扩展应用、改变已有认识。

最后形成：
别人以前做到哪里
→ 我这次做了什么
→ 我发现了什么
→ 因此我新增了什么知识/价值

例如：
“我们首次验证了 X 在 Y 场景中的有效性，并发现 X 能显著改善 Z。”
前半句是成就，后半句开始体现贡献。
- 具体写出自己的贡献
  - 写贡献时，必须明确“这是本研究做出来的”，不要只写一个孤立结论。

1. 强调“我们做了什么”
   用：
   We developed...
   We proposed...
   We conducted...
适合写方法、模型、实验。

2. 强调“我们发现了什么”
   用：
   We found that...
   Our results show that...
   Our findings suggest that...
适合写主要结果。

3. 强调“研究证明了什么”
   用：
   This study demonstrates that...
   This study provides evidence that...
适合把结果上升为研究结论。

4. 强调“贡献在哪里”
   用：
   The main contribution is...
   This study extends previous work by...
   This work provides new evidence for...
适合 Discussion / Conclusion。

时态简单记：
做过的事 → 过去时
We developed / found / observed...
现在仍成立的结论 → 现在时
Our results show... / This study demonstrates...
强调“已经完成并形成成果” → 现在完成时
We have developed / demonstrated...

最核心的写作顺序：
我们做了什么
→ 我们发现了什么
→ 这个发现说明什么
→ 相比前人新增了什么
## 6. 怎么写摘要

### 提高摘要的清晰度和连贯性

- 明确地指明你的贡献。
  - 核心原则：摘要里要让读者一眼分清“前人已知什么”和“这篇论文新做了什么”。

前人知识：
It is known that...
Previous studies have shown that...
It has been previously demonstrated that...

本文工作：
In this study, we...
Here, we...
Our results show that...
We demonstrate that...

时态：
做了什么 → 过去时：We developed / found / analysed...
已经完成且成果仍有效 → 现在完成时：We have developed / demonstrated...

语态：
尽量主动写 We...，少用模糊被动句，这样贡献归属更清楚。

最重要的一句：

摘要不是只让读者“看懂”，而是要让读者明确知道：哪些是已有知识，哪些是你这篇论文的新贡献。
- 避免指代词的歧义。
  - 指代词像it、which或this可能对你而言是清楚易懂的，但对读者则不然。如果可能存在歧义，请在this之类的词后面加上适当的名词或重复名词/短语。正如你将在摘要4（第6.2.1节）中看到的，为了避免歧义，短语the hybrid method 在一个140个单词的摘要中重复了至少4次。
- 使用一致的语言
  - 如果某个东西被描述为一种途径(approach)，它不应该突然成为一个方案(scheme)。类似地，一个方案(scheme)不应该突然成为一个框架(framework)，一个模型(model)不应该突然成为一种方法(method)，一个工具(tool)也不应该突然成为一个设备(device)。这样会模糊你提供的内容的身份，也使摘要难以理解。
- 使用第一单元中描述的句子开头的技巧
  - 句子开头的核心作用：给读者“指路”。

具体就做 4 件事：
承接上句：This result... / These findings...
转折：However, ...
因果：Therefore, ...
强调重点：Importantly, ...

写法上遵循：
已知信息放句首 → 新信息放句尾。
这样每句话都能接住上一句，再自然引出下一句。
- 保持句子长度简短
  - 少于20个单词的句子在第一次阅读时能被90%的读者理解，那些超过40个单词的句子在第一次阅读时只能被10%的读者理解。本单元《英语科技写作》第6.2小节中的18个摘要的平均句子长度为22个单词。
### 摘要的字数和段落

- 字数：
一般约 80～250 词，具体以目标期刊要求为准；最好再看该期刊近期论文的平均长度。

段落：
多数摘要写成一个完整段落。

核心原则：
不要为了凑满字数把所有内容都塞进去。
摘要也不是“整篇论文压缩版”，而是优先突出最重要的信息。
### 什么时候开始写摘要？

- 摘要通常是在论文的其他部分都完成以后才写的。
### 摘要的类型

- 1.简单的/一般的摘要
- 2.有结构的摘要，具有如背景/目的/方法/结果(Background/Aims/Method/Results)等的标题
- 3.与重要性说明(a Significance Statement)或亮点(Highlights)的列表在一起的摘要
- 4.图形摘要
### 摘要的写作模板

- 通用摘要模板
- 写作时态
  - 和以往一样，你的目标文章提供最好的指导，但一般而言：
1. 当提及论文/研究做了什么或者在论文里有什么的时候，大多数作者用一般现在时。
2. 当提及已经做了什么或者用了什么的时候，即方法，大多数作者用一般过去时。
3. 结果和含义可以用一般过去时或一般现在时。摘要以一种能够立即吸引读者注意力的方式呈现论文的内容，因此，摘要中的结果和含义有时会使用现在时，即使这些结果和含义在论文正文中以过去时表示。
4. 成果/价值/贡献可以用现在完成时(have+ed)或一般现在时来表达。
- 摘要部分不要包含引文！
- 尽量不要在摘要部分提供背景信息，如果需要背景信息来理解摘要本身，请用尽可能少的词来组合和总结相关要点。
- 是否包含方法和结论的一些细节
  - 摘要里的方法和结果只留“最关键的”。
方法：
写核心方法、模型、数据或实验设计；普通步骤和设备细节删掉。
结果：
写最重要、最能证明贡献的结果；关键数字可以保留，最好带比较。

判断标准：
删掉后会不会影响读者理解“你怎么做、做得怎么样”？会 → 留。不会 → 删。
- 摘要如何强调结果？
  - 原则：
1. 结果很确定 → 可以直接写强结论。
2. 结果还有不确定性 → 用 may / might / could / possible / potential 弱化语气。

摘要中的结论必须和正文、数据一致，不能为了“吸引人”把话说得比证据更强。
- 如何限制字数使摘要保持流畅？
  - 摘要字数有限时，核心不是“硬删字”，而是“让一句话承担多个功能”。

具体做法：
1. 保留句子之间的连接，不要为了省字把过渡词全删掉，否则信息会变成一条条孤立事实。
2. 合并相关信息，一两句话可以同时完成：做了什么 + 得到什么结果；方法 + 结果；结果 + 研究空白；结果 + 意义/解释。
3. 优先删重复，不删逻辑，背景细节、普通步骤、重复描述可以删；但“为什么转到下一句”的逻辑要保留。
4. 每句话都要有任务，最好一条句子至少传递一个核心信息，必要时同时承担两个相关功能。
## 7. 撰写标题

### 分析目标期刊最近可比较的标题

- 检查平均长度
  - 先统计目标期刊近期论文标题的平均长度，把它作为参考。标题不要为了简短而删掉关键信息，也不要塞入过多细节；核心标准是简洁、清楚、信息完整，平均长度只是参考，不是硬性规定。
- 使用缩写
  - 标题中应尽量少用缩写。只有领域内非常通用、读者基本都认识的缩写才适合直接使用；生僻或自创缩写会降低标题的可读性、理解速度和检索效果。
- 将标题关键字与关键字列表进行比较
  - 把标题和论文的 Keywords 放在一起检查。最核心的研究对象、问题或方法最好出现在标题中；关键词列表则可以补充标题中放不下的相关术语、同义词等，从而提高论文的搜索和发现概率。
- 检查标题的语法
  - 重点检查标题有没有歧义、修饰关系不清或连续名词堆砌。尤其要看“哪个词修饰哪个词”是否明确；如果标题需要读两遍才能理解，就应该通过介词、连字符或调整语序重新表达。
- 映射和建立目标文章标题的结构性内容的模板
  - 收集目标期刊的优秀标题，分析它们常用的结构，例如：
研究对象 + 方法 + 目的/结果、X 对 Y 的影响、A method for B、主标题：副标题等。总结出期刊偏好的“标题骨架”，再把自己的研究内容套进去，而不是照抄具体标题。
- 检查标题所建议的期望是否在论文中得到满足
  - 标题相当于给读者一个研究承诺。论文完成后逐项检查：标题中提到的研究对象、方法、变量、关系和结论，正文是否真的研究并证明了；如果标题说得比结果更大，就要缩小标题，避免夸大或名不副实。
