# 通用 PPT 页面美化与生图

## Trigger check
适用于逐页美化或重绘现有幻灯片、截图或文字内容；独立的科研图表规划不适用，应使用相应科研绘图技能。

适用于任意行业、主题与页面类型。**不得将智矿卫士、矿山、黑金、高亮或任何特定品牌作为所有 PPT 的默认内容或风格**。用户最新指令、原页面内容和当前任务指定的风格优先；`references/style-and-lessons.md` 与 `assets/` 中的黑金矿山方案只是可选案例，不是通用模板。

## 1. 确定输入和范围

1. 读取用户最新给出的 PPT、页面截图或文字，并按实际文件确认页数；最新指定截图优先于旧导出。不要从旧案例猜测名称、数据或页数。
2. 确认任务范围、页码、输出目录、是否替换文件、期望比例和分辨率；从用户指令或文件中获取，不必重复询问。单页先处理指定页；批量按要求逐页生成，不擅自增删页面。
3. 优先使用原生视觉识图；用户指定 OCR 时按其要求使用。可从 PPT 的文本对象辅助核对，但不能忽略图片内信息。
4. 为每页区分：**内容原稿**、用户提供的照片／截图等**真实素材**、仅供视觉参考的**风格页**和**字体参考**。用户指定 PPT 某页作为字体参考时重新导出并附上；禁止把风格页的文字混进当前页。
5. 未指定设计风格时优先沿用当前演示文稿已确认的视觉语言和排版；需要示例时选择当前任务的示例。仅当用户要求黑金矿山风格或明确选择该套案例时，才阅读 `references/style-and-lessons.md` 并使用其中 `assets/`。

## 2. 内容与素材保真

- 默认保留原页面的标题、正文、数字、单位、标点、日期、名称、品牌名、项目名、编号、表格行列、图表数据、模块数量、逻辑顺序与箭头方向。用户明确要求改写时按其要求执行；不得编造。
- 标志、校徽、商标、标志性图标、照片、人物、证书、报告、截图和图表不能凭空重画成冒充原件。需要真实保留时从原始 PPT 或用户附件提取、按页面相应位置合成；若不可完成，要说明具体限制。
- 图片框是否留空以当前用户指令和最新原稿为准。需要保留原图就显示原图；明确要求占位时保留对应位置和数量，不能把占位误报为原始素材。模型接收参考图片不等于实际复制了原素材。
- 信息密集页优先清楚呈现所有文字、图表标签、脚注和底部小字，减少装饰、提高对比度并合理排版；禁止通过删字、改数字换取清晰。必要时用原 PPT 文字对象和真实素材重排或叠加。
- 用户要求局部修改时，只修改对应区域，尽量保持其他画面、标志和文字；指定参考图标时保留其原有形状，不自行换成其他图案。

## 3. 生图流程

1. 用户指定 Magpie 时使用 `magpie-image` MCP 的 `generate_image`；调用前查看当前工具接口。其他指定工具遵循用户选择，且不虚构工具能力。参考图选择本页原稿、用户选定的风格页、字体页及相关真实素材；明确标注角色。
2. 提示词写明画幅、用户指定或现有统一风格、页面结构及需要逐字保留的文字和关键数据；根据每页实际情况描述图片、表格及箭头。不要把任何案例的公司名、标志、字体或颜色硬套到其他项目。
3. 输出规格以用户要求为准；未指定时以原页比例为准。若用户要求高清 16:9，可请求 `size: "3840x2160"`、`quality: "high"`；实际宽高必须以生成文件为准。使用用户指定目录，没有指定时使用合理的项目输出目录。
4. 若返回异步 ID，按接口获取该 ID 的最终结果；不重复提交仍在运行的任务。对于失败查看真实错误并限量重试；记录成功、失败和运行中页码与 ID，不把提交当完成。
5. 生成后直接检查图片与原页：内容及数据、素材位置、标志、字体、风格一致性、实际分辨率；密集页特别检查图表、脚注与最小文字。模型输出出现错字、缺图、错误数据或分辨率不足时不得宣称合格。
6. 用户明确要求替换旧文件时，生成成功并完成针对性检查后再替换指定文件；没有明确要求则保存新文件，不覆盖原件。用户接受预览不等于保真与清晰度全部达标。

## 4. 交付

提供可访问的输出路径、实际尺寸，以及已检查或未能确认的内容；照片、文字、图表与标志未经过真实素材复核时明确说明。请求分辨率、模型声称和简单放大都不等于实际高清细节。无法达到要求时清楚说明未达项，不编造结果。
