# 通用 PPT 页面美化与生图

## Trigger check
适用于逐页美化或重绘现有幻灯片、截图或文字内容；独立的科研图表规划不适用，应使用相应科研绘图技能。

适用于任意行业、主题与页面类型。**不得将智矿卫士、矿山、黑金、高亮或任何特定品牌作为所有 PPT 的默认内容或风格**。用户最新指令、原页面内容和当前任务指定的风格优先；`references/style-and-lessons.md` 与 `assets/` 中的黑金矿山方案只是可选案例，不是通用模板。

## 1. 确定输入和范围

1. 读取用户最新给出的 PPT、页面截图或文字，并按实际文件确认页数；最新指定截图优先于旧导出。不要从旧案例猜测名称、数据或页数。
2. 确认任务范围、页码、输出目录、是否替换文件、期望比例和分辨率；从用户指令或文件中获取，不必重复询问。单页先处理指定页；批量按要求逐页生成，不擅自增删页面。
3. 优先使用原生视觉识图；用户明确指定或禁止 OCR 时遵从其要求。可从 PPT 的文本对象辅助核对，但不能忽略图片内信息。
4. 为每页区分：**内容原稿**、用户提供的照片／截图等**真实素材**、仅供视觉参考的**风格页**和**字体参考**。用户指定 PPT 某页作为字体参考时重新导出并附上；禁止把风格页的文字混进当前页。
5. 未指定设计风格时优先沿用当前演示文稿已确认的视觉语言和排版；需要示例时选择当前任务的示例。仅当用户要求黑金矿山风格或明确选择该套案例时，才阅读 `references/style-and-lessons.md` 并使用其中 `assets/`。

## 2. 内容与素材保真

- 默认保留原页面的标题、正文、数字、单位、标点、日期、名称、品牌名、项目名、编号、表格行列、图表数据、模块数量、逻辑顺序与箭头方向。用户明确要求改写时按其要求执行；不得编造。
- 标志、校徽、商标、标志性图标、照片、人物、证书、报告、截图和图表不能凭空重画成冒充原件。需要真实保留时从原始 PPT 或用户附件提取、按页面相应位置合成；若不可完成，要说明具体限制。
- 图片框是否留空以当前用户指令和最新原稿为准。需要保留原图就显示原图；明确要求占位时保留对应位置和数量，不能把占位误报为原始素材。模型接收参考图片不等于实际复制了原素材。
- 信息密集页优先清楚呈现所有文字、图表标签、脚注和底部小字，减少装饰、提高对比度并合理排版；禁止通过删字、改数字换取清晰。必要时用原 PPT 文字对象和真实素材重排或叠加。
- 用户要求局部修改时，只修改对应区域，尽量保持其他画面、标志和文字；指定参考图标时保留其原有形状，不自行换成其他图案。

## 3. 分层制作与 8K 大屏工作流

当用户要求高清、大屏、保留真实素材或生成的整页图片文字不清晰时，优先使用分层制作，而不是放大整页 AI 生图；用户明确指定制作方式时遵从其要求，并说明保真和分辨率限制。

1. **盘点原稿**：读取 PPT 页数、画幅和页面对象；逐页检查图片、文字、图表和形状。PPTX 可作为 ZIP 查看 `ppt/media/` 中嵌入的原文件，并通过幻灯片关系和对象结构定位所属页面。记录图片原始像素、位置、大小、裁剪、旋转、层级；组合对象、蒙版和效果也需核对。检查母版、版式、图片填充、SVG/EMF 等可能不以普通图片对象出现的素材。已经合成在截图中的内容无法还原为独立原件；遇到复杂裁剪、矢量格式、蒙版或不支持的对象时，先对照渲染结果验证能否忠实还原，不能还原则优先保留原页面对象并报告限制，不得静默替换或遗漏。
2. **保留真实素材**：校徽、照片、证书、报告、截图和图表优先使用 PPT 嵌入原件或用户新提供的原图，按原裁剪与布局放入页面；不得用生成内容冒充真实素材。用户要求替换照片时，根据内容选择相应位置，保持比例并适当裁剪，检查主体和文字未被遮挡。提取不能恢复原图没有的细节；低分辨率报告应提示提供原 PDF 或高清扫描件。
3. **分层合成**：使用用户指定且可用的生图工具制作背景、光效等装饰，提示词明确不要生成文字、数字、标志、照片和不需要的框线。关键文字、数字、表格、流程图和线条优先保留或重建为 PowerPoint 原生文本及矢量对象；真实素材作为独立图像叠加。保持用户指定的布局和风格，不得把纯背景当成完整成品。可编辑 PPT 可作为中间成果或按需交付；避免重新保存时压缩嵌入素材，并核查实际保存效果。
4. **导出与分辨率**：依据原始比例导出，16:9 的 8K 为 7680×4320。先确认本机可用的 PowerPoint 或其他渲染工具及字体；例如 Windows 上可通过 PowerPoint 对单页执行 `Slide.Export(绝对路径, "PNG", 7680, 4320)`，实际支持情况以运行结果为准。导出后用图片库读取实际像素，并检查渲染是否出现字体替换或版式变化；失败、尺寸被限制或字体缺失时，保留中间成果，尝试本机可用的其他可靠渲染方式，仍无法满足则报告实际结果和限制，不能把放大图称作原生 8K。分别记录 AI 背景、重要照片与最终图像的原始尺寸。输出 8K 画布不代表所有元素为原生 8K；插值放大不会恢复真实细节。评估关键文字与素材按最终展示尺寸的可读性，必要时建议更大的文字或高清原件；不能未经确认删改原内容。
5. **逐页核验**：比较原稿、风格参考与最终合成图，核对文字、数字、顺序、照片、裁剪及标志；检查遮挡、溢出、对比度和密集页面小字。确认背景位于内容底层、未遮挡文字图片；对照原始素材核查保留内容，检查替换照片确实显示在指定位置、主体与裁剪正确。核验素材原始数据是否保留时可比较嵌入文件哈希，但对象或哈希一致不等于视觉正确。验证导出尺寸；大图无法直接查看时可生成预览图，同时以原始像素 100% 裁剪检查标题、正文最小字、照片及证书图表等关键区域，不能仅凭缩略图确认细节。实际屏幕、播放设备及输出链路未测试时明确说明。
6. **先做样页**：批量制作前，当用户要求试验或存在分辨率、风格不确定性时，先完成指定样页，供确认后再扩展；不得将测试结果误报为全套完成。

## 4. 生图流程

1. 用户指定 Magpie 时使用 `magpie-image` MCP 的 `generate_image`；调用前查看当前工具接口。其他指定工具遵循用户选择，且不虚构工具能力。参考图选择本页原稿、用户选定的风格页、字体页及相关真实素材；明确标注角色。
2. 按制作路径编写提示词：**仅生成背景**时，描述画幅、风格、色彩与留白区域，明确禁止文字、数字、标志、照片和不需要的框线；原稿文字与真实素材在后续合成，不写成背景生成内容。**整页重绘**时，写明页面结构及需要逐字保留的文字、关键数据、图片、表格和箭头；生成后仍需核对并修正文字、数据及真实素材，不能把模型重画视为原件。两条路径均不得把案例的公司名、标志、字体或颜色硬套到其他项目。
3. 输出规格以用户要求为准；未指定时以原页比例为准。若用户要求高清 16:9，且当前工具接口支持，可请求 `size: "3840x2160"`、`quality: "high"`；这只是 4K 示例，不代替用户指定的 8K 或其他规格，实际宽高必须以生成文件为准。使用用户指定目录，没有指定时使用合理的项目输出目录。
4. 若返回异步 ID，按接口获取该 ID 的最终结果；不重复提交仍在运行的任务。对于失败查看真实错误并限量重试；记录成功、失败和运行中页码与 ID，不把提交当完成。
5. 生成后直接检查图片与原页：内容及数据、素材位置、标志、字体、风格一致性、实际分辨率；密集页特别检查图表、脚注与最小文字。模型输出出现错字、缺图、错误数据或分辨率不足时不得宣称合格。
6. 用户明确要求替换旧文件时，生成成功并完成针对性检查后再替换指定文件；没有明确要求则保存新文件，不覆盖原件。用户接受预览不等于保真与清晰度全部达标。

## 5. 文件组织与交付

- 以当前任务或指定页为单位集中存放，例如在用户指定输出目录下建立 `第02页/成品/` 与 `第02页/素材/`：成品放完整页面图片及需要时的可编辑 PPT；素材放用户照片、提取素材、参考页、生成背景和必要的裁剪信息。可根据现有项目结构调整，不散落在多个无关目录。
- 用户只要求图片时，首要交付可直接查看的**完整成品图**，内嵌预览并提供原图路径；预览、背景、参考图和中间文件须清晰命名，禁止把空白背景作为成品展示或链接。仅在任务需要时额外交付可编辑文件。
- 尊重已有文件与引用：默认不覆盖原稿或已有结果，不擅自删除、迁移可能仍被引用的旧文件；明确要求替换时按上节核验后替换指定文件。新版本集中保存，必要时说明旧文件仍在原处。用户明确要求整理已有文件时，先核对来源、目标和重名冲突，保留可追溯性。
- 提供可访问的输出路径、实际尺寸，以及已检查或未能确认的内容；照片、文字、图表与标志未经过真实素材复核时明确说明。请求分辨率、模型声称和简单放大都不等于实际高清细节。无法达到要求时清楚说明未达项，不编造结果。
