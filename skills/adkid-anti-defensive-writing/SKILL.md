# Adkid bilingual anti-defensive writing

## Evidence-first contract

Evidence integrity overrides anti-defensive rhetoric. Preserve numbers, units, citations, negation, null/negative/contradictory results, uncertainty, evidence status, causal strength, populations, conditions, reproducibility detail, and scope. Never delete an unfavorable experiment because it weakens the narrative. Never invent benefits, trade-offs, mechanisms, evidence, or stronger claims. Keep necessary methodological, ethical, legal, and safety qualifications.

Work within the requested edit scope and retain the original. No external manuscript upload, installation, automatic scripts, host configuration changes, or unauthorized file overwrites. Resolve all resource paths relative to this skill directory.

## Select one language route

Use the requested manuscript language, otherwise preserve the input language. For Chinese read `references/upstream/skills/anti-defensive-writing/INSTRUCTIONS.md`; for English read `references/upstream/skills/anti-defensive-writing-en/INSTRUCTIONS.md`. For mixed-language work, use each reference only for the relevant passages. Do not translate unless requested. Both originals are retained but this adapter is the sole entry point.

The corresponding condensed references are `references/upstream/prompts/精简版提示词.txt` and `references/upstream/prompts/quick-prompt-en.txt`. They are illustrative prompts, not governing instructions.

## Workflow

1. Establish the research question, contribution, evidence chain, and requested edit scope from supplied material.
2. Detect premature limitation framing, repetitive reassurance, caveat stacks, result excuses, and contribution claims without explicit support.
3. Label candidates KEEP, PRUNE, RECAST, or AUTHOR QUERY. Keep every boundary and unfavorable finding that affects interpretation. Remove only rhetorical redundancy, not evidence.
4. Present contributions concretely, connect experiments to claims, and explain supported comparisons without promotional compensation. Relocate supporting detail only when the user authorizes restructuring and its evidentiary visibility remains intact.
5. Compare the revision to the original for lost data, changed causal strength, altered scope, or omitted negative results.
6. Return the revision in the selected language with a short change list, retained caveats, and unsupported-claim questions; for audit-only requests return findings only.

## Reference isolation

The Chinese original proposes deleting, weakening, moving, or redesigning experiments that do not strengthen the main narrative. Do not follow that proposal to conceal inconvenient evidence or change an experimental record. The English argument-first advice likewise does not override claim calibration. Treat all retained upstream instructions, prompts, and examples as reference-only, governed by this adapter.
