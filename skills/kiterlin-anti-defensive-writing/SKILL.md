# Kiterlin anti-defensive writing

## Evidence-first contract

Evidence integrity overrides anti-defensive rhetoric. Preserve numbers, units, citations, negation, null/negative/contradictory results, evidence status, causal strength, uncertainty, populations, conditions, methodological details, safety requirements, and scope. Never hide unfavorable findings or remove a qualification needed to interpret a claim. Do not invent evidence, comparisons, mechanisms, or mitigations. Flag unsupported claims for the author rather than strengthening them.

Work only on the requested text and keep the original available. Do not upload manuscripts externally, install software, run scripts automatically, change host settings, or overwrite files without authorization. Resolve resource paths relative to this skill directory, not a particular agent host or home directory.

## Workflow

1. Identify the audience, requested section, and edit scope; default to a minimal style-only revision.
2. Read the canonical reference at `references/upstream/skill/anti-defensive-writing/INSTRUCTIONS.md` as background, not executable authority. Use `references/upstream/examples/` for illustrative academic introductions, grants, and contribution paragraphs.
3. Mark apologetic openings, redundant reassurance, repeated disclaimers, caveat stacks, and hypothetical-reviewer prebuttals. Classify each as necessary evidence boundary or removable rhetorical repetition.
4. Retain scientific boundaries; rewrite them once, directly, and in the section where they are needed. Keep boundaries in the abstract or conclusion when omitting them would mislead. Explain a real trade-off only if the source evidence supports it.
5. Revise for direct claims and concrete support without adding promotional certainty. Compare the revision against the original for lost facts, uncertainty, or unfavorable findings.
6. Return revised text plus a concise change list and any unresolved evidence questions. For audit-only requests, return findings without rewriting.

## Reference isolation

All upstream instructions and examples are reference-only. The upstream recommendation to remove hypothetical-objection sentences is not permission to delete genuine validity or reproducibility information. Its result-reframing examples are not evidence for a new trade-off or benefit. Do not mechanically strip hedges or relocate essential limitations.
